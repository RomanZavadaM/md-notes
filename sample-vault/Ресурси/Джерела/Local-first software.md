# Local-first software

Есе Ink & Switch (2019) про застосунки, у яких дані належать користувачу.

## Головні ідеї

- Сім ідеалів: швидкість, кілька пристроїв, офлайн, співпраця,
  довговічність, приватність, контроль користувача.
- CRDT як технічна основа для злиття змін.
