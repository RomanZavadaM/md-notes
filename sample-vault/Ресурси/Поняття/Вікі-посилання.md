# Вікі-посилання

Синтаксис посилань між нотатками:

| Запис | Значення |
|---|---|
| `[[Нотатка]]` | посилання на нотатку |
| `[[Нотатка\|текст]]` | посилання з іншим текстом |
| `[[Нотатка#Розділ]]` | посилання на розділ |
| `![[файл.png]]` | вбудувати файл |

Посилання всередині коду, як `[[це]]`, ігноруються.

## Діаграма

```mermaid
graph LR
  A[Нотатка] -- "[[посилання]]" --> B[Інша нотатка]
  B -- зворотне посилання --> A
```

## Формула

Щільність зв'язків бази з $n$ нотаток і $m$ посилань:

$$
D = \frac{m}{n(n-1)}
$$
