# Модель даних

## Сховище

Сховище (vault) — це папка з нотатками.

```
моя-база/
├── .mdnotes/              службова папка
│   ├── config.json        налаштування сховища
│   ├── schema.json        типи нотаток і їхні поля
│   ├── templates/         шаблони нотаток
│   ├── views/             збережені вигляди (*.view.json)
│   ├── cache/             індекс index.db — локальний, не синхронізується
│   ├── trash/             кошик — локальний, не синхронізується
│   └── .gitignore         виключає cache/ і trash/
├── attachments/РРРР/ММ/   вкладення
└── ...                    нотатки і папки користувача
```

Чому індекс лежить у `cache/`, а не в корені `.mdnotes`, пояснює
[ADR-0002](adr/0002-index-location.md).

### `config.json`

```json
{
  "version": 1,
  "name": "Моя база",
  "attachmentsDir": "attachments",
  "dailyNotesDir": "daily"
}
```

Усі поля необов'язкові. Без `config.json` застосовуються значення за
замовчуванням.

## Нотатка

Нотатка — це файл `.md` (або `.markdown`) у кодуванні UTF-8 з необов'язковим
YAML front matter:

```markdown
---
id: 01JA2B3C4D5E6F7G8H9J0KMNPQ
type: task
title: Реалізувати дерево файлів
tags: [mdnotes, ui]
status: done
due: 2026-10-15
project: "[[MD Notes]]"
created: 2026-10-01
---

# Реалізувати дерево файлів

Текст нотатки з [[посиланнями]] і #тегами.
```

### Чотири механізми структури

| Механізм | Синтаксис | Роль |
|---|---|---|
| Папки | шлях файлу | грубе групування: «де лежить» |
| Посилання | `[[Назва]]`, `[[Назва\|текст]]`, `[[Назва#Розділ]]`, `![[файл]]` | зв'язки між знаннями, головна структура бази |
| Теги | `#тег`, `#область/підтема`, властивість `tags` | наскрізні теми |
| Властивості | YAML front matter | машиночитні характеристики |

Правила розбору (реалізовано в `notes-core/src/markdown.rs`):

- Посилання і теги всередині коду (`` `…` `` і блоків ```` ``` ````) ігноруються.
- Тег починається з `#` на початку рядка або після пробілу. Він може містити
  літери будь-якої мови, цифри, `_`, `-`, `/`. Число на кшталт `#123` тегом
  не вважається.
- Заголовок нотатки — властивість `title`, або перший заголовок `# …`, або
  ім'я файлу.
- Посилання `[[Назва]]` знаходить нотатку спершу за шляхом, потім за іменем
  файлу без урахування регістру. Пошук за `aliases` з'явиться разом з
  індексом.

### Стандартні властивості

| Поле | Тип | Опис |
|---|---|---|
| `id` | рядок (ULID) | стабільний ідентифікатор; не змінюється при перейменуванні ([ADR-0004](adr/0004-note-identifiers.md)) |
| `type` | рядок | тип нотатки (див. нижче) |
| `title` | рядок | заголовок, якщо відрізняється від імені файлу |
| `tags` | список рядків | теги |
| `status` | рядок | стан (для задач і проєктів) |
| `created`, `updated` | дата `РРРР-ММ-ДД` | дата створення та зміни |
| `aliases` | список рядків | інші назви, за якими працюють посилання |
| `related` | список посилань | явні пов'язані нотатки |

Невідомі властивості зберігаються як є: застосунок нічого не видаляє з
front matter.

## Типи нотаток

| Тип | Призначення | Додаткові поля |
|---|---|---|
| `note` | звичайна нотатка, ідея | — |
| `concept` | поняття, термін | `aliases` |
| `project` | проєкт | `status`, `start`, `due` |
| `task` | задача | `status`, `due`, `priority`, `project` |
| `person` | людина, контакт | `org`, `role` |
| `meeting` | зустріч | `date`, `participants` |
| `source` | книга, стаття, документ | `author`, `url`, `attachment` |
| `daily` | щоденна нотатка | `date` |
| `moc` | карта змісту — хаб теми | — |

Типи описуються в `.mdnotes/schema.json`. Приклад —
[sample-vault/.mdnotes/schema.json](../sample-vault/.mdnotes/schema.json).
Користувач може додавати свої типи та поля. За схемою застосунок показує
форму замість сирого YAML (v0.2).

### Формат `schema.json`

```json
{
  "version": 1,
  "fields": {
    "status": { "type": "enum", "values": ["todo", "doing", "done"] },
    "due": { "type": "date" },
    "project": { "type": "link", "noteType": "project" }
  },
  "types": {
    "task": {
      "label": "Задача",
      "template": "task.md",
      "fields": ["status", "due", "priority", "project"],
      "required": ["status"]
    }
  }
}
```

Типи полів: `text`, `number`, `date`, `datetime`, `bool`, `enum`, `list`,
`link`, `links`, `url`, `file`.

## Вкладення

- Додані файли копіюються в `attachments/РРРР/ММ/`.
- У нотатці зберігається стандартне відносне посилання Markdown, сумісне з
  GitHub: `![схема](../attachments/2026/10/schema.png)`.
- При перейменуванні або переміщенні нотаток і файлів посилання оновлюються
  автоматично (v0.2, разом з індексом).
