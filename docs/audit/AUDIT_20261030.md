## 1. Що це
Настільний (і мобільний каркас) застосунок для Markdown-нотаток зі сховищем-текою, зв'язками й графом, шифрованим сховищем, Git-синхронізацією, резервним копіюванням і багатовіконним режимом. Власницька ліцензія. Інтерфейс і документація — сім мов.

## 2. Архітектура
- **Ядро:** Rust, крейт `notes-core` (індекс, сховище за трейтом `StorageProvider`, ідентифікатори нотаток, синхронізація/конфлікти, шифрування age, злиття ідентичностей, Git). Найбільші модулі: `index.rs` (1099 рядків), `git_sync.rs` (850).
- **Застосунок:** Tauri 2 + React/TypeScript у `app/`; `src-tauri/src/lib.rs` (852 рядки) — команди; вікна: головне, граф, редактор (відокремлені вікна з адресними подіями — ADR-0010). Найбільший файл інтерфейсу — `App.tsx` (1416 рядків), `KnowledgeGraphPanel.tsx` (824).
- **Рішення:** ADR 0001–0010 (`docs/adr/`).
- **Випуски:** `release-please` формує PR випуску, збірки в Actions, префікси комітів керують версією; усі випуски — пререлізи. Версія: `Cargo.toml`, `app/package.json`, `tauri.conf.json`.
- **CI:** окремі завдання `ci.yml` (з класифікацією змінених шляхів), `mobile-smoke.yml`, `lockfiles.yml`, `release.yml`; зміни лише в `*.md`/`docs/**` пропускають CI.

## 6. Рекомендації
1. **MDN-01/02 (високий):** для кожної з 15 гілок (13+2) перевірити, чи зміст є в `main` (`git diff main…гілка` по файлах), далі `archive_branch.py --apply` і, лише з дозволу власника, видалення. Для git-pull v0.3 — підтвердити, що злиті PR (за записом у журналі — #59–#61; не перевірено) перекривають роботу.
2. **MDN-03 (середній):** протокол приймання ADR-0010 перенести на модель «один PR, раунди — коментарі, артефакти — `workflow_dispatch` на голову PR» (STRATEGY 4.4); підсумок раундів — один абзац в ADR.
3. **MDN-04 (високий):** Vitest у `app/`: (а) паритет ключів усіх мов (перенести скрипт у CI), (б) чисті функції графа (`liveLayout`, `treeLayout`, `overlay`), (в) 3-5 тестів компонентів із відкритими/зашифрованими станами. Мета першого кроку: ≥30 тестів, крок у `ci.yml`.
4. **MDN-05 (середній):** `PROJECT_STATE.md` ≤150 рядків (замінюється), `WORKLOG.md` — щомісячна ротація в `docs/archive/`, issue #8 або WORKLOG (не обидва).
5. **MDN-06 (середній):** один спосіб злиття (squash) + автовидалення; набір правил для `main` (заборона видалення/force-push, вимога CI) — репозиторій публічний, тому доступно.
6. **MDN-07 (середній):** розібрати журнали збою 29.10 19:19 і записати причину; якщо збій очікуваний — виключити гілки release-please з обов'язкових перевірок явно.
7. **MDN-08 (середній):** узгодити з власником політику незалежності: вбудувати WebView2 у портативний архів Windows (готовий приклад), або явно задокументувати залежність.
8. **MDN-09 (низький):** розбити `App.tsx` за областями (вікна, панелі, стан) при наступній фічі.
9. **MDN-10 (низький):** `git fetch --prune`, видалити локальні `gone`-гілки, повернути робочу теку на `main` (після завершення роботи сесії, що нею користується).
