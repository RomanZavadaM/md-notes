# Roadmap

Порядок етапів змінено порівняно з початковим планом. Мобільна версія без
синхронізації мало корисна, тому базова синхронізація (Git і WebDAV)
переїхала у v0.3, разом з Android та iOS. Причини описані в
[ADR-0003](adr/0003-storage-providers.md) і
[ADR-0006](adr/0006-mobile-file-access.md).

## v0.1 — ядро і настільна версія ✅ поточна

- [x] Монорепо: Cargo workspace, Tauri 2, React + Vite, CI на трьох ОС
- [x] `notes-core`: відкриття сховища, дерево файлів, читання й атомарний запис
- [x] Розбір front matter, `[[посилань]]`, `#тегів`, заголовків
- [x] Створення, перейменування, переміщення в кошик
- [x] Редактор CodeMirror 6, перегляд, режим «поруч», автозбереження
- [x] Перехід за `[[посиланням]]` і створення відсутньої нотатки
- [x] Світла, темна і системна теми, адаптивне компонування
- [x] Приклад сховища, документація, ADR
- [ ] Відстеження змін файлів ззовні (notify)
- [ ] Строга CSP для вебвікна

## v0.2 — структура і зв'язки

- Індекс SQLite у `.mdnotes/cache/index.db`, інкрементальне оновлення
- Повнотекстовий пошук (FTS5), швидкий перехід `Ctrl+O`
- Зворотні посилання, пошук за `aliases`
- Оновлення посилань при перейменуванні та переміщенні
- Вкладення: копіювання в `attachments/РРРР/ММ/`, перегляд зображень і PDF,
  «де використовується», файли без посилань
- Типи нотаток, `schema.json`, шаблони, форма властивостей
- Створення сховища з пресетом: PARA, Zettelkasten, порожнє
- Граф знань (sigma.js): глобальний і локальний
- Mermaid і KaTeX у перегляді

## v0.3 — мобільні платформи і синхронізація

- Android та iOS: доступ до папок через SAF та security-scoped bookmarks
- Git-сховище (gitoxide): clone, pull, commit, push у фоні
- WebDAV через OpenDAL
- Local-first: локальна копія, черга змін, конфлікти як окремі файли
- Паролі й токени в системному сховищі секретів (keyring)
- Таблиці (TanStack Table) і мова запитів
- Мобільні режими: таблиця як картки

## v0.4 — час і задачі

- Канбан (dnd-kit), на мобільних по одній колонці
- Календар, часова шкала
- Щоденні нотатки
- SFTP і S3-сумісні сховища

## v0.5 — хмари і полотно

- Google Drive, OneDrive, Dropbox
- Полотно у форматі JSON Canvas (React Flow)
- Інтелект-карти (markmap), галерея вкладень

## v0.6 — історія версій

- Історія нотатки з Git, порівняння версій, відновлення
- SMB (через системне монтування або окрему бібліотеку)

## v1.0 — публікація

- Microsoft Store, Mac App Store, Google Play, App Store
- Підписування коду, автооновлення для настільних версій
- Стабілізація форматів `config.json`, `schema.json`, `*.view.json`
