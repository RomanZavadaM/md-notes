# MD Notes — ユーザーガイド

**v0.1.0** 対象。ウクライナ語版が正本です。

## 1. 初回起動

1. お使いの OS 用の MD Notes をインストールします (README を参照)。
2. **「フォルダーを開く」** を押し、ノートのフォルダーを選択します。`.md` ファイルのあるフォルダーなら何でもよく、リポジトリの `sample-vault/` も使えます。
3. MD Notes はフォルダーを記憶し、次回起動時に開きます。

フォルダーを開いても内容は変更されません。サービスフォルダー `.mdnotes/` は、実際に必要になったとき (ゴミ箱、設定、インデックス) にのみ作成されます。

## 2. 画面構成

- **ツールバー** — サイドバーボタン ☰、保管庫名、開いているノートのタイトル (点は未保存の変更を示します)、「エディター」/「並列」/「プレビュー」モード、テーマの選択。
- **サイドバー** — 保管庫のファイルツリー。フォルダーが先に表示され、隠しフォルダー (`.mdnotes`、`.git`) は表示されません。他の形式のファイルはグレーで表示されます。
- **作業領域** — エディター、プレビュー、または両方を並べて表示。
- **ステータスバー** — ノートのパス、タグ、リンク数、プロパティのエラー、保存状態。

狭い画面では、サイドバーは内容の上に開き、ノートを選ぶと閉じます。

## 3. ノートとフォルダー

- **+ ノート** は選択したフォルダー (または選択したファイルの隣) にノートを作成します。タイトルがファイル名になり、ファイル名に使えない文字は除かれます。
- 新しいノートには `id` (固定の識別子)、`type: note`、`created` のプロパティが付きます。
- **+ フォルダー** はフォルダーを作成します。
- **✎** は選択した項目の名前を変更します。拡張子 `.md` は自動で付きます。
- **🗑** は項目を保管庫のゴミ箱 `.mdnotes/trash/` に移動します。完全には削除されないため、ファイルは手動で戻せます。

## 4. 編集

- 入力をやめると間もなく自動保存され、`Ctrl+S` / `Cmd+S` でも保存できます。
- 書き込みはアトミックで、保存中に障害が起きてもファイルが壊れることはありません。
- **「並列」** モードではエディターとプレビューを同時に表示します。プレビューは GitHub Flavored Markdown (表、タスクリスト、取り消し線) に対応します。

## 5. リンク

- `[[ノートのタイトル]]` は別のノートへのリンクで、プレビューでクリックできます。
- `[[タイトル|テキスト]]` は別のテキストを表示し、`[[タイトル#セクション]]` はセクションへリンクします。
- その名前のノートがなければ、クリックで作成されます。
- リンクはパス、次にファイル名の順に、大文字と小文字を区別せずに解決されます。コード内のリンクは無視されます。
- 通常の `https://…` リンクはシステムのブラウザーで開きます。

## 6. タグとプロパティ

- 本文の `#タグ` またはプロパティの `tags` リストでテーマを示します。入れ子のタグ `#プロジェクト/デザイン` にも対応します。
- プロパティはファイル先頭の `---` 行の間に YAML front matter として記述します。
- プレビューでは、プロパティは **「プロパティ」** ブロックに折りたたまれます。
- YAML にエラーがあるとステータスバーに表示され、ノートは通常のテキストとして開きます。

## 7. テーマ

ツールバー右端で **システム**、**ライト**、**ダーク** を選びます。選択は保存されます。

## 8. データの保存場所

- ノートは選択したフォルダー内の通常のファイルで、MD Notes がなくても使えます。
- `.mdnotes/` は保管庫のサービスフォルダーです: 設定、テンプレート、ゴミ箱、キャッシュ。
- MD Notes はデータをどこにも送信しません。サーバー、分析、テレメトリーはありません。
- 保管庫フォルダーをバックアップしてください。バージョン管理には Git が便利です。

## 9. キーボード

| 操作 | Windows / Linux | macOS |
|---|---|---|
| 保存 | `Ctrl+S` | `Cmd+S` |
| 元に戻す / やり直し | `Ctrl+Z` / `Ctrl+Shift+Z` | `Cmd+Z` / `Cmd+Shift+Z` |
| インデント | `Tab` | `Tab` |

## 10. よくある問題

- **Windows が SmartScreen を表示する** — コード署名のないビルドです。「詳細情報 → 実行」を選択してください。
- **macOS でアプリが開かない** — 公証されていないビルドです。**システム設定 → プライバシーとセキュリティ → このまま開く** を使用してください。
- **起動時に保管庫が開かない** — フォルダーの名前が変わったか移動されました。**「別の保管庫…」** から開き直してください。
- **ノートが開かない** — MD Notes が開くのは `.md` と `.markdown` ファイルのみです。
