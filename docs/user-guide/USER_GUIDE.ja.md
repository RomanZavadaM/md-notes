# MD Notes — ユーザーガイド

[🇺🇦 Українська](USER_GUIDE.uk.md) · [🇬🇧 English](USER_GUIDE.en.md) · [🇫🇷 Français](USER_GUIDE.fr.md) · [🇩🇪 Deutsch](USER_GUIDE.de.md) · [🇪🇸 Español](USER_GUIDE.es.md) · [🇰🇷 한국어](USER_GUIDE.ko.md) · **🇯🇵 日本語**

**v0.3.15** 対象。ウクライナ語版が正本です。

## 1. 初回起動

1. お使いの OS 用の MD Notes をインストールします (README を参照)。
2. 必要に応じて、ようこそ画面で表示言語を選びます。
3. **「フォルダーを開く」** を押し、ノートのフォルダーを選択します。`.md` ファイルのあるフォルダーなら何でもよく、リポジトリの `sample-vault/` も使えます。
4. MD Notes はフォルダーを記憶し、次回起動時に開きます。

フォルダーを開いてもノートは変更されません。MD Notes は検索インデックス、ゴミ箱、設定のためにサービスフォルダー `.mdnotes/` を作成します。

## 2. 画面構成

- **ツールバー**:
  - サイドバーボタン ☰ と保管庫名;
  - 開いているノートのタイトル: クリックするとクイック移動が開き、点は未保存の変更を示します;
  - 「エディター」/「並列」/「プレビュー」モード;
  - リンクパネルのボタン ⇆;
  - テーマと言語の選択、「このアプリについて」ボタン ⓘ。
- **サイドバー** — **ファイル**、**検索**、**タグ** のタブ。
  - ファイルツリーではフォルダーが先に表示され、隠しフォルダー (`.mdnotes`、`.git`) は表示されません。
  - 他の形式のファイルはグレーで表示されます。
- **作業領域** — エディター、プレビュー、または両方を並べて表示。
- 右側の **「リンク」パネル** — 開いているノートのバックリンク、発リンク、タグ。
- **ステータスバー** — ノートのパス、タグ、リンク数、プロパティのエラー、保存状態。

狭い画面では、サイドバーとリンクパネルは内容の上に開きます。

## 3. ノートとフォルダー

- **+ ノート** は選択したフォルダー (または選択したファイルの隣) にノートを作成します。ダイアログで **テンプレート** を選べます (9 章)。
- タイトルがファイル名になり、ファイル名に使えない文字は除かれます。新しいノートには `id`、`type`、`created` のプロパティが付きます。
- **今日** はデイリーノートを開きます (9 章)。
- **+ フォルダー** はフォルダーを作成します。
- **✎** は選択した項目の名前を変更します。拡張子 `.md` は自動で付きます。**名前を変えたノート、または名前を変えたフォルダー内のノートへのリンクは、プロパティを含む他のすべてのノートで更新されます。** 何件のノートでリンクを更新したかが表示されます。
- **🗑** は項目を保管庫のゴミ箱 `.mdnotes/trash/` に移動します。完全には削除されないため、ファイルは手動で戻せます。

## 4. 編集

- 入力をやめると間もなく自動保存され、`Ctrl+S` / `Cmd+S` でも保存できます。
- 書き込みはアトミックで、保存中に障害が起きてもファイルが壊れることはありません。
- 他のプログラム (エディター、Git、クラウドクライアント) がファイルを変更すると、MD Notes はツリーを更新し、開いているノートを読み直します。未保存の変更がある場合は、保存すると外部の変更が上書きされることを警告します。

## 5. プレビュー

- GitHub Flavored Markdown: 表、タスクリスト、取り消し線。
- **Mermaid 図** — 言語 `mermaid` のコードブロック。
- **KaTeX 数式** — 行内の `$…$` とブロックの `$$…$$`。
- 保管庫の **画像**: 相対パス `![](../attachments/2026/10/図.png)` または埋め込み `![[図.png]]`。表示されるのは開いている保管庫内のファイルだけです。
- `.md` ファイルへの相対リンクはアプリ内でノートを開き、`https://…` リンクはシステムのブラウザーで開きます。

## 6. リンク

- `[[ノートのタイトル]]` は別のノートへのリンクで、プレビューでクリックできます。
- `[[タイトル|テキスト]]` は別のテキストを表示し、`[[タイトル#セクション]]` はセクションへリンクします。
- その名前のノートがなければ、クリックで作成されます。
- リンクはパス、ファイル名、または `aliases` プロパティで、大文字と小文字を区別せずに解決されます。コード内のリンクは無視されます。
- プロパティ内のリンク (`project: "[[MD Notes]]"`) も対象です。
- **「リンク」** パネル (⇆) には、開いているノートにリンクしているノートが前後の行とともに表示されます。

## 7. 検索、タグ、クイック移動

- **検索** (`Ctrl+Shift+F` / `Cmd+Shift+F`) はすべてのノートの本文とタイトルを検索します。検索語の各単語は単語の先頭に一致します。タイトルの一致が上位に表示され、見つかった語は強調されます。
- **タグ** — すべてのタグとノート数。タグを選ぶと、入れ子のタグを含めてそのノートが表示されます (`#プロジェクト` は `#プロジェクト/デザイン` も検出)。
- **クイック移動** (`Ctrl+O` / `Cmd+O`、`Ctrl+P` も可) — タイトル、エイリアス、パスの一部を入力します。`↑`/`↓` で選び、`Enter` で開きます。ノートがなければ `Enter` で作成されます。

## 8. タグとプロパティ

- 本文の `#タグ` またはプロパティの `tags` リストでテーマを示します。見出しの末尾のタグはノートのタイトルに含まれません。
- プロパティはファイル先頭の `---` 行の間に YAML front matter として記述します。
- プレビューでは、プロパティは **「プロパティ」** ブロックに折りたたまれます。
- YAML にエラーがあるとステータスバーに表示され、ノートは通常のテキストとして開きます。

## 9. テンプレートとデイリーノート

- テンプレートは `.mdnotes/templates/` にある通常の `.md` ファイルです。一覧の種類名は `.mdnotes/schema.json` から取得されます。
- プレースホルダー: `{{title}}` — タイトル、`{{date}}` — 日付 `YYYY-MM-DD`、`{{time}}` — 時刻 `HH:MM`、`{{id}}` — 新しい識別子。
- **今日** はデイリーノート用フォルダー (`.mdnotes/config.json` の `dailyNotesDir`、既定は `daily`) の `YYYY-MM-DD.md` を開きます。存在しなければ `daily` テンプレートから作成されます。

## 10. テーマと言語

- テーマ: **システム**、**ライト**、**ダーク**。
- 表示言語: 🇺🇦 Українська (基本) · 🇬🇧 English · 🇫🇷 Français · 🇩🇪 Deutsch · 🇪🇸 Español · 🇰🇷 한국어 · 🇯🇵 日本語。
- どちらの選択も保存されます。**「このアプリについて」** ウィンドウ (ⓘ) にはバージョン、権利者、言語一覧が表示されます。

## 11. データの保存場所

- ノートは選択したフォルダー内の通常のファイルで、MD Notes がなくても使えます。
- `.mdnotes/` は保管庫のサービスフォルダーです: 設定、テンプレート、ゴミ箱、キャッシュ。
- `.mdnotes/cache/index.db` は検索とリンクのインデックスです。キャッシュにすぎないため、削除しても再構築されます。キャッシュとゴミ箱は Git の対象外です (`.mdnotes/.gitignore`)。
- MD Notes はデータをどこにも送信しません。サーバー、分析、テレメトリーはありません。
- 保管庫フォルダーをバックアップしてください。バージョン管理には Git が便利です。

### 暗号化保管庫（任意）

- 保管庫の作成時に**「保管庫を暗号化」**を選びます。ノートは `.age` ファイルとしてディスクに保存され、鍵がなければ読めません。
- 作成直後に秘密鍵（`AGE-SECRET-KEY-…`）が**一度だけ**表示されます。パスワードマネージャーまたはオフラインで保管してください。復元はできません。以後、鍵はこの端末のシステムのシークレットストアにのみ保管されます。
- **復旧用の公開鍵**（`age1…`）を指定できます。メインの鍵を失っても、この鍵で保管庫を開けます。
- 別のコンピューターでは保管庫のフォルダーをコピーして開きます。アプリが鍵を求めるので、秘密鍵を貼り付けると、そのコンピューターのシステムのシークレットストアに保存されます。
- 現時点では、暗号化保管庫では画像と添付ファイルが表示されず、`.mdnotes/cache` インデックスは暗号化されません。

## 12. グラフ、関係ツリー、対象の検索

### グラフ

**「リンク」**パネルには「リンク」「ローカルグラフ」「グローバルグラフ」のタブがあります。ノードはノート、色はノートの `type`、線は `[[…]]` リンクまたは型付き関係です。ノードをクリックするとノートが開きます。

- **生きた物理（「浮遊する」グラフ）。** ノードをドラッグすると隣のノードが付いてきて避け、放すとグラフがなめらかに落ち着きます。**「浮遊」**ボタンはゆるやかなゆらぎを加え（400ノードまでは初期設定でオン）、**「一時停止」**で動きを止めます。**「力」**で中心、反発、リンクの強さ、リンクの長さのスライダーを調整でき、選択は記憶されます。
- **型付き関係**は `relations` プロパティに書きます（`to` と、`type`、`grade`、`origin`、`status`、`evidence`、逆方向は `dir: in`）。`grade` は文字と数字です（A1 が最も信頼でき、F6 が最も弱い）。文字は情報源、数字は主張の確からしさを表します。線とノードの輪郭は評価に従い、5〜6 の評価には**「噂」**の表示が付きます。色だけで区別することはありません。
- **「出所」**は、選んだノードの上にある所有者の連鎖と周りの資料を強調表示します。
- **別ウィンドウ。** グラフのタブの **↗** ボタン、または「ファイル → 別ウィンドウでグラフを開く」（デスクトップのみ）で、より広い専用ウィンドウ（たとえば2台目のモニター）にグラフを開けます。アクティブなノートに追従し、変更後に更新され、ノードをクリックするとメインウィンドウでノートが開きます。

### 関係ツリー

**「関係ツリー」**タブは、選んだノートからの型付き関係の連鎖を表示します：**「所有者と出典」**（上方向）または**「所有しているもの」**（下方向）、深さ 1〜8。

- 各ノードに関係の種類と線の評価が表示され、その横に**「チェーン」**評価が出ます。ルートからの経路で最も弱いリンクです（B2 と C1 は C2）。連鎖は最も弱いリンクまでしか信頼できません。
- **「−/+」**で枝を折りたたみ、**◎**で別のノードからツリーを作り直し、**「すべて展開」/「すべて折りたたむ」**で全ての枝を操作します。重複するノードには印が付き二度は展開されません。ツリーは400ノードまでです。
- **「2つのノート間の経路」**は型付き関係の最短の連鎖（線の向きは無視）を探し、最も弱いリンクを表示します。
- ツリーは明示的な型付き関係のみを使い、通常のリンクは使いません。チェーン評価は補助であり、法的な結論ではありません。

### コードまたは名前で対象を探す

**「検索」**タブでは、8桁の数字は EDRPOU コード、10桁は納税者番号として検索します（先頭の0が失われた6〜7桁のコードは復元されます）。結果は分けて表示されます。

- **「完全一致」**：`edrpou` または `ipn` プロパティに同じコードを持つノート（または正規化後に同じ名前）；
- **「名前の候補」**：似た名前。名前の一致は**証拠ではない**ので、コードか文書で確認してください；
- **「本文」**：通常の全文検索。

名前は大文字小文字、引用符、ハイフン、法人形態（LLC など）を無視して比較され、キリル文字に似たラテン文字はキリル文字にそろえられます。

### フォルダーのインポート、コードによる統合、重複の可能性

- **「ファイル → フォルダーをインポート…」**はフォルダー内のノートを追加します。コード（`edrpou`/`ipn`）が保管庫に既にあるノートは、重複せず既存のノートに**統合**されます。足りないプロパティは追加され、タグ、エイリアス、関係はまとめられ、インポートしたノートのタイトルはエイリアスになり、異なる値は上書きされずに確認用に一覧されます。同じフォルダーを再度インポートしても何も変わりません。
- **「ファイル → 重複の可能性…」**は、正規化したタイトルまたはエイリアスが同じノートのグループを表示します。ヒントに過ぎず、何も変更されず、コードが異なるノートが同じグループになることはありません。

## 14. よくある問題

- **Windows が SmartScreen を表示する** — コード署名のないビルドです。「詳細情報 → 実行」を選択してください。
- **macOS でアプリが開かない** — 公証されていないビルドです。**システム設定 → プライバシーとセキュリティ → このまま開く** を使用してください。
- **起動時に保管庫が開かない** — フォルダーの名前が変わったか移動されました。**「別の保管庫…」** から開き直してください。
- **変更したばかりのノートが検索で見つからない** — 保管庫を閉じて開き直してください。それでも直らない場合は `.mdnotes/cache/index.db` を削除すると、インデックスが再構築されます。
- **画像が表示されない** — ファイルが保管庫内にあり、パスが相対パスであることを確認してください。
