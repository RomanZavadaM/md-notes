# MD Notes — 사용자 가이드

[🇺🇦 Українська](USER_GUIDE.uk.md) · [🇬🇧 English](USER_GUIDE.en.md) · [🇫🇷 Français](USER_GUIDE.fr.md) · [🇩🇪 Deutsch](USER_GUIDE.de.md) · [🇪🇸 Español](USER_GUIDE.es.md) · **🇰🇷 한국어** · [🇯🇵 日本語](USER_GUIDE.ja.md)

**v1.0.0** 기준입니다. 우크라이나어판이 기준 문서입니다.

## 1. 처음 실행

1. OS에 맞는 MD Notes를 설치합니다 (README 참고). Windows의 v1.0 NSIS/MSI 설치 프로그램에는 offline WebView2와 VC runtime이 포함되며 portable ZIP은 Windows에 이미 설치된 WebView2 Runtime을 사용합니다.
2. 필요하면 시작 화면에서 인터페이스 언어를 고릅니다.
3. **「폴더 열기」**를 누르고 노트 폴더를 선택합니다. `.md` 파일이 있는 어떤 폴더든 되며, 저장소의 `sample-vault/`도 사용할 수 있습니다.
4. MD Notes는 폴더를 기억하고 다음 실행 때 다시 엽니다.

폴더를 열어도 노트는 바뀌지 않습니다. MD Notes는 검색 인덱스, 휴지통, 설정을 위해 서비스 폴더 `.mdnotes/`를 만듭니다.

## 2. 화면 구성

- **도구 모음**:
  - 사이드바 버튼 ☰와 보관함 이름;
  - 열린 노트 제목: 클릭하면 빠른 이동이 열리고, 점은 저장되지 않은 변경을 뜻합니다;
  - 「편집기」 / 「나란히」 / 「미리보기」 모드;
  - 링크 패널 버튼 ⇆;
  - 테마·언어 선택, 「정보」 버튼 ⓘ.
- **사이드바** — **파일**, **검색**, **태그** 탭.
  - 파일 트리에서는 폴더가 먼저 표시되며, 숨김 폴더(`.mdnotes`, `.git`)는 보이지 않습니다.
  - 다른 형식의 파일은 회색으로 표시됩니다.
- **작업 영역** — 편집기, 미리보기, 또는 둘을 나란히.
- 오른쪽 **「링크」 패널** — 열린 노트의 백링크, 나가는 링크, 태그.
- **상태 표시줄** — 노트 경로, 태그, 링크 수, 속성 오류, 저장 상태.

좁은 화면에서는 사이드바와 링크 패널이 내용 위에 열립니다.

## 3. 노트와 폴더

- **+ 노트**는 선택한 폴더(또는 선택한 파일 옆)에 노트를 만듭니다. 대화 상자에서 **템플릿**을 고를 수 있습니다(9장).
- 제목이 파일 이름이 되며, 파일 이름에 쓸 수 없는 문자는 제거됩니다. 새 노트에는 `id`, `type`, `created` 속성이 붙습니다.
- **오늘**은 데일리 노트를 엽니다(9장).
- **+ 폴더**는 폴더를 만듭니다.
- **✎**는 선택한 항목의 이름을 바꿉니다. `.md` 확장자는 자동으로 붙습니다. **이름을 바꾼 노트, 또는 이름을 바꾼 폴더 안의 노트를 가리키는 링크는 속성을 포함해 다른 모든 노트에서 갱신됩니다.** 몇 개의 노트에서 링크를 갱신했는지 알려 줍니다.
- **🗑**는 항목을 보관함 휴지통 `.mdnotes/trash/`로 옮깁니다. 영구 삭제되지 않으므로 파일을 직접 되돌릴 수 있습니다.
- **다중 선택:** `Ctrl`(Windows/Linux) 또는 `Cmd`(macOS)를 누른 채 클릭하면 항목을 선택에 추가하거나 선택에서 뺄 수 있고, `Shift`는 트리에 현재 보이는 범위를 선택합니다. 일반 클릭은 단일 선택과 기존 열기 동작으로 돌아갑니다.
- 여러 항목이 선택된 상태에서 **🗑**를 누르면 한 번에 휴지통으로 옮깁니다. 폴더와 그 안의 항목을 동시에 선택해도 내부 항목을 두 번 처리하지 않습니다. 이름 바꾸기는 아직 하나의 선택 항목에만 사용할 수 있습니다.

## 4. 편집

- 입력을 멈추면 곧 자동 저장되며, `Ctrl+S` / `Cmd+S`로도 저장됩니다.
- 쓰기는 원자적으로 이루어져 저장 도중 문제가 생겨도 파일이 손상되지 않습니다.
- 다른 프로그램(편집기, Git, 클라우드 클라이언트)이 파일을 바꾸면 MD Notes가 트리를 새로 고치고 열린 노트를 다시 읽습니다. 저장되지 않은 변경이 있으면, 저장할 경우 외부 변경을 덮어쓴다고 경고합니다.

## 5. 미리보기

- GitHub Flavored Markdown: 표, 작업 목록, 취소선.
- **Mermaid 다이어그램** — 언어가 `mermaid`인 코드 블록.
- **KaTeX 수식** — 줄 안의 `$…$`, 블록의 `$$…$$`.
- 보관함의 **이미지**: 상대 경로 `![](../attachments/2026/10/도식.png)` 또는 삽입 `![[도식.png]]`. 열린 보관함 안의 파일만 표시됩니다.
- `.md` 파일로 가는 상대 링크는 앱에서 노트를 열고, `https://…` 링크는 시스템 브라우저에서 열립니다.

## 6. 링크

- `[[노트 제목]]`은 다른 노트로 연결되며 미리보기에서 클릭할 수 있습니다.
- `[[제목|텍스트]]`는 다른 텍스트를 표시하고, `[[제목#섹션]]`은 섹션으로 연결됩니다.
- 해당 이름의 노트가 없으면 클릭할 때 새로 만들어집니다.
- 링크는 경로, 파일 이름 또는 `aliases` 속성으로 대소문자 구분 없이 찾습니다. 코드 안의 링크는 무시됩니다.
- 속성 안의 링크(`project: "[[MD Notes]]"`)도 인식합니다.
- **「링크」** 패널(⇆)은 열린 노트를 링크한 노트를 문맥 줄과 함께 보여 줍니다.

## 7. 검색, 태그, 빠른 이동

- **검색**(`Ctrl+Shift+F` / `Cmd+Shift+F`)은 모든 노트의 본문과 제목을 찾습니다. 검색어의 각 단어는 단어의 시작 부분과 일치합니다. 제목에서 일치하는 결과가 위에 오고, 찾은 단어는 강조 표시됩니다.
- **태그** — 모든 태그와 노트 수. 태그를 고르면 중첩 태그를 포함해 해당 노트가 표시됩니다(`#프로젝트`는 `#프로젝트/디자인`도 찾음).
- **빠른 이동**(`Ctrl+O` / `Cmd+O`, `Ctrl+P`도 가능) — 제목, alias, 경로의 일부를 입력합니다. `↑`/`↓`로 고르고 `Enter`로 엽니다. 노트가 없으면 `Enter`로 새로 만듭니다.

## 8. 태그와 속성

- 본문의 `#태그` 또는 속성의 `tags` 목록으로 주제를 표시합니다. 제목 끝의 태그는 노트 제목에 포함되지 않습니다.
- 속성은 파일 맨 앞 `---` 줄 사이에 YAML front matter로 작성합니다.
- 미리보기에서 속성은 **「속성」** 블록에 접혀 표시됩니다.
- YAML에 오류가 있으면 상태 표시줄에 표시되고, 노트는 일반 텍스트로 열립니다.

## 9. 템플릿과 데일리 노트

- 템플릿은 `.mdnotes/templates/`에 있는 일반 `.md` 파일입니다. 목록의 유형 이름은 `.mdnotes/schema.json`에서 가져옵니다.
- 자리 표시자: `{{title}}` — 제목, `{{date}}` — 날짜 `YYYY-MM-DD`, `{{time}}` — 시간 `HH:MM`, `{{id}}` — 새 식별자.
- **오늘**은 데일리 노트 폴더(`.mdnotes/config.json`의 `dailyNotesDir`, 기본값 `daily`)의 `YYYY-MM-DD.md` 노트를 엽니다. 없으면 `daily` 템플릿으로 만듭니다.

## 10. 테마와 언어

- 테마: **시스템**, **라이트**, **다크**.
- 인터페이스 언어: 🇺🇦 Українська (기본) · 🇬🇧 English · 🇫🇷 Français · 🇩🇪 Deutsch · 🇪🇸 Español · 🇰🇷 한국어 · 🇯🇵 日本語.
- 두 선택 모두 저장됩니다. **「정보」** 창(ⓘ)에서 버전, 저작권자, 언어 목록을 볼 수 있습니다.

## 11. 데이터 저장 위치

- 노트는 선택한 폴더의 일반 파일이며, MD Notes 없이도 사용할 수 있습니다.
- `.mdnotes/`는 보관함의 서비스 폴더입니다: 설정, 템플릿, 휴지통, 캐시.
- `.mdnotes/cache/index.db`는 검색·링크 인덱스입니다. 캐시일 뿐이므로 지워도 다시 만들어집니다. 캐시와 휴지통은 Git에서 제외됩니다(`.mdnotes/.gitignore`).
- MD Notes는 데이터를 어디에도 보내지 않습니다. 서버, 분석, 원격 측정이 없습니다.
- 보관함 폴더를 백업하세요. 버전 관리에는 Git이 편리합니다.

### 암호화 보관함 (선택)

- 보관함을 만들 때 **“보관함 암호화”**를 선택하세요. 노트는 디스크에 `.age` 파일로 저장되며 키 없이는 읽을 수 없습니다.
- 생성 직후 개인 키(`AGE-SECRET-KEY-…`)가 **한 번만** 표시됩니다. 비밀번호 관리자나 오프라인에 보관하세요. 복구할 수 없습니다. 이후 키는 이 기기의 시스템 비밀 저장소에만 보관됩니다.
- **복구용 공개 키**(`age1…`)를 지정할 수 있습니다. 기본 키를 잃어버려도 이 키로 보관함을 열 수 있습니다.
- 다른 컴퓨터에서는 보관함 폴더를 복사해 여세요. 앱이 키를 요청합니다. 개인 키를 붙여넣으면 그 컴퓨터의 시스템 비밀 저장소에 저장됩니다.
- 1.0 안정화에서는 암호화 보관함의 이미지와 PDF를 디스크에 평문 복사본을 쓰지 않고 표시합니다. 데이터는 메모리에서만 복호화됩니다. 기존 암호화 vault에서는 **파일 → “복구 키 관리…”**로 공개 `age1…` recipient를 추가할 수 있습니다. 암호화 첨부파일의 외부 “파일 열기”는 비활성화되며 `.mdnotes/cache` 인덱스는 계속 암호화되지 않습니다.

### Git (데스크톱 전용)

**Git** 버튼(또는 메뉴의 “Git…”)은 패널을 엽니다. 저장소 만들기, 원격 주소 지정, 접근 정보 저장(토큰은 시스템 비밀 저장소에만 보관됨), 그리고 **fetch**, **pull**, **commit**, **push**를 할 수 있습니다. pull은 저장하지 않은 변경이 없고 원격에 새 내용만 있을 때만 실행되며, 기록이 갈라졌다면 수동 결정이 필요합니다. push에는 컴퓨터에 Git이 설치되어 있어야 합니다. 암호화 보관함에서는 push 전에 모든 파일이 암호화되었는지 확인하며, 그렇지 않으면 차단됩니다.

## 12. 그래프, 관계 트리, 대상 조회

### 그래프

**“링크”** 패널에는 “링크”, “로컬 그래프”, “글로벌 그래프” 탭이 있습니다. 노드는 노트이고 색은 노트의 `type`, 선은 `[[…]]` 링크 또는 유형이 지정된 관계입니다. 노드를 클릭하면 노트가 열립니다.

- **살아 있는 물리(“떠다니는” 그래프).** 노드를 끌면 이웃 노드가 따라오고 피해 가며, 놓으면 그래프가 부드럽게 안정됩니다. **“부유”** 버튼은 약한 흔들림을 더하며(노드 400개 이하에서는 기본 켜짐), **“일시정지”**는 움직임을 멈춥니다. **“힘”**에서 중심, 반발력, 링크 강도, 링크 길이를 조절할 수 있고 선택은 기억됩니다.
- **“도형”과 “범례”.** **“도형”** 버튼은 **도형**이 노트 유형을 보여 주는 모드를 켭니다(사람 — 머리와 어깨, 회사 — 사각형, 기관 — 육각형, 사건 — 마름모, 자료 — 삼각형, 그룹 — 점 세 개). **노드 색**은 관계의 최고 등급이 나타내는 **신뢰도**를 보여 줍니다(초록 1–2, 호박색 3–4, 빨강 5–6, 회색 — 등급 없음). **“범례”**를 펼치면 모든 도형, 색, 선 스타일을 볼 수 있습니다. 점선 윤곽과 “Ч” 표시는 소문을 뜻하며 색만으로 구분하지 않습니다.
- **“관계 표시” 필터.** 그래프 패널의 목록은 선택한 등급 이상의 관계만 남깁니다(“신뢰” — 1–2, “신뢰와 보통” — 1–4). 등급 없는 관계와 단순 링크는 숨겨지고 노드는 그대로 남습니다.
- **유형 관계**는 `relations` 속성에 씁니다(`to`, 그리고 `type`, `grade`, `origin`, `status`, `evidence`, 반대 방향은 `dir: in`). `grade`는 문자와 숫자입니다(A1이 가장 신뢰, F6이 가장 약함): 문자는 출처, 숫자는 주장의 신빙성입니다. 선과 노드 윤곽은 등급을 따르며 5–6등급에는 **“소문”** 표시가 붙습니다. 색만으로 구분하지 않습니다.
- **“어디서 왔나”**는 선택한 노드 위의 소유자 사슬과 주변 자료를 강조합니다.
- **별도 창.** 그래프 탭의 **↗** 버튼 또는 “파일 → 별도 창에서 그래프 보기”(데스크톱 전용)로 더 넓은 자체 창에서 그래프를 열 수 있습니다(예: 두 번째 모니터). 활성 노트를 따라가고 변경 후 갱신되며, 노드를 클릭하면 기본 창에서 노트가 열립니다.
- **“뒤로” 버튼.** 그래프 창에서 이전 노트로 돌아갑니다.

### 관계 트리

**“관계 트리”** 탭은 선택한 노트에서 시작하는 유형 관계 사슬을 보여 줍니다: **“소유자와 출처”**(위로) 또는 **“소유한 대상”**(아래로), 깊이 1–8.

- 각 노드는 관계 종류와 선 등급을 보여 주며, 옆에 **“체인”** 등급이 있습니다. 루트에서 오는 경로의 가장 약한 고리입니다(B2와 C1은 C2). 사슬은 가장 약한 고리만큼만 신뢰할 수 있습니다.
- **“−/+”**는 가지를 접고, **◎**는 다른 노드에서 트리를 다시 만들며, **“모두 펼치기” / “모두 접기”**는 모든 가지를 제어합니다. 반복되는 노드는 표시되고 두 번 펼치지 않으며 트리는 400개 노드로 제한됩니다.
- **“두 노트 사이의 경로”**는 유형 관계의 가장 짧은 사슬(선 방향 무시)을 찾아 가장 약한 고리를 보여 줍니다. **“가장 짧은 경로 대신 가장 신뢰할 수 있는 경로”** 체크박스는 가장 약한 고리가 가장 좋은 연쇄를 찾습니다(신뢰도가 같으면 단계가 가장 적은 것).
- 트리는 명시적 유형 관계만 사용하며 일반 링크는 사용하지 않습니다. 체인 등급은 보조 지표일 뿐 법적 결론이 아닙니다.

### 코드나 이름으로 대상 찾기

**“검색”** 탭에서 8자리 숫자는 EDRPOU 코드로, 10자리 숫자는 납세 번호로 조회합니다(앞의 0이 사라진 6–7자리 코드는 복원됩니다). 결과는 구분해서 표시됩니다. 8자리 코드이면 아래에 **“코드로 보는 “З-під Ляди” 데이터”** 블록이 나타납니다. 사이트의 공개 데이터 폴더(data 브랜치의 로컬 사본)를 선택하면 정확한 코드에 대한 사실, 즉 등록일, 상태, 창립자와 실소유자의 외국 국가(등기부), 경쟁당국 결정, 발주자·낙찰자로서의 Prozorro 조달을 보여 줍니다. 읽기 전용이며 네트워크로 전송되는 것은 없습니다. 평가가 아니라 사실입니다.

- **“정확히 일치”**: `edrpou` 또는 `ipn` 속성에 같은 코드가 있는 노트(또는 정규화 후 같은 이름);
- **“이름 후보”**: 비슷한 이름. 이름 일치는 **증거가 아니므로** 코드나 문서로 확인하세요;
- **“본문”**: 일반 전체 텍스트 검색.

이름은 대소문자, 따옴표, 하이픈, 법인 형태(LLC 등)를 무시하고 비교하며, 키릴 문자와 비슷한 라틴 문자는 키릴 문자로 통일됩니다.

### 폴더 가져오기, 코드로 병합, 중복 가능성

- **“파일 → 폴더 가져오기…”**는 폴더의 노트를 추가합니다. 코드(`edrpou`/`ipn`)가 이미 보관함에 있는 노트는 중복되지 않고 기존 노트에 **병합**됩니다. 없는 속성은 추가되고 태그, 별칭, 관계는 합쳐지며 가져온 노트의 제목은 별칭이 되고, 다른 값은 덮어쓰지 않고 검토용으로 나열됩니다. 같은 폴더를 다시 가져와도 변하는 것이 없습니다.
- **“파일 → 중복 가능성…”**은 정규화한 제목이나 별칭이 같은 노트 그룹을 보여 줍니다. 힌트일 뿐이며 아무것도 바뀌지 않고, 코드가 다른 노트는 같은 그룹이 되지 않습니다.

## 14. 자주 겪는 문제

- **Windows가 SmartScreen을 표시함** — 코드 서명이 없는 빌드입니다. 「추가 정보 → 실행」을 선택하세요.
- **macOS에서 앱이 열리지 않음** — 공증되지 않은 빌드입니다. **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**를 사용하세요.
- **실행 시 보관함이 열리지 않음** — 폴더 이름이 바뀌었거나 옮겨졌습니다. **「다른 보관함…」**으로 다시 여세요.
- **방금 바꾼 노트가 검색되지 않음** — 보관함을 닫았다가 다시 여세요. 그래도 안 되면 `.mdnotes/cache/index.db`를 지우면 인덱스가 다시 만들어집니다.
- **이미지가 표시되지 않음** — 파일이 보관함 안에 있고 경로가 상대 경로인지 확인하세요.

## 탭과 독립 편집기 창

**v0.3.21**에서는 여러 보관함 노트를 탭으로 동시에 열 수 있습니다. 각 탭은 독립적인 초안을 유지하므로 노트를 전환해도 저장되지 않은 텍스트가 사라지지 않아야 합니다.

데스크톱에서 활성 보관함 노트에는 **별도 창에서 열기**가 있습니다. MD Notes는 분리하기 전에 현재 초안을 저장합니다. 독립 창이 성공적으로 생성되면 해당 노트는 기본 편집기의 탭에서 제거되고, 기본 창은 이전 탭으로 돌아갑니다. 남은 탭이 없으면 보관함 트리는 유지한 채 빈 편집 영역을 표시합니다. 독립 창에서는 편집기 / 나란히 / 미리보기 모드와 자동 저장을 사용할 수 있습니다.

외부 `.md/.markdown` 파일은 별도 문서로 유지되며 보관함으로 자동 가져오기 되지 않습니다. M3가 이제 통합되었습니다. 다른 창이나 프로세스가 열린 뒤 파일을 변경하면 MD Notes는 조용한 덮어쓰기를 차단하고, 변경된 분리 창은 보호 저장이 성공할 때까지 닫히지 않으며, 전체 종료는 먼저 모든 열린 문서를 안전하게 처리합니다. 이 기능은 공개된 **v0.3.21**에 포함되며, M4는 실제 데스크톱 시스템에서의 수동 런타임 검증 단계입니다.


## 보관함 백업

**파일** 메뉴의 **백업 만들기…**를 사용합니다. 백업을 만들기 전에 MD Notes는 열린 모든 탭을 저장하려고 합니다. 결과는 `manifest.json`을 포함하는 이동 가능한 ZIP이며, 각 파일의 경로·크기·SHA-256을 기록합니다.

노트, 첨부 파일, 서비스 설정, 템플릿, `.mdnotes/trash`는 포함하고 `.git`, `.mdnotes/cache`, 임시 시스템 파일은 제외합니다. 암호화 보관함은 디스크의 암호화 파일을 그대로 복사하며 개인/복구 키는 ZIP에 넣지 않습니다.

**백업 복원…**은 쓰기 전에 매니페스트, 경로, 크기, SHA-256을 모두 검증합니다. 검증이 끝난 뒤에만 임시 폴더에 풀고 새 보관함 폴더를 만듭니다. 기존 폴더는 절대 덮어쓰지 않습니다.
