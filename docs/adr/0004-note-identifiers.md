# ADR-0004: Стабільні ідентифікатори нотаток

- Статус: прийнято
- Дата: 2026-10-01

## Контекст

Нотатки перейменовують і переміщують. Вигляди, полотна й історія мають
посилатися на нотатку незалежно від її шляху. Водночас файли можуть
з'являтися ззовні (інший редактор, GitHub) без жодних властивостей.

## Рішення

- Ідентифікатор — **ULID** (26 символів, сортується за часом створення),
  поле `id` у front matter.
- Застосунок додає `id` **лише нотаткам, які створює сам**.
- Файли без `id` повноцінно працюють. Для них індекс використовує шлях як
  тимчасовий ключ.
- `id` дописується в наявну нотатку лише тоді, коли він справді потрібен:
  на нотатку посилається полотно чи вигляд, або користувач редагує
  властивості через форму. Про це повідомляється в інтерфейсі, і функцію
  можна вимкнути в `config.json`.
- Якщо два файли мають однаковий `id` (копія файлу), застосунок показує
  попередження і пропонує згенерувати новий `id` для копії.

## Наслідки

- Зовнішні файли не змінюються без потреби, що відповідає принципу «дані
  належать користувачу».
- Посилання `[[Назва]]` у тексті лишаються людиночитними, а `id`
  використовується лише в машинних форматах (`*.canvas`, `*.view.json`).
