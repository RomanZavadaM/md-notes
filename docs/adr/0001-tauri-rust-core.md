# ADR-0001: Tauri 2 і ядро на Rust

- Статус: прийнято
- Дата: 2026-10-01

## Контекст

Потрібні Windows, macOS, Android та iOS з однієї кодової бази. Застосунок
працює з файловою системою, мережевими сховищами й індексом, тому логіка
даних має бути швидкою, надійною і тестованою незалежно від інтерфейсу.

## Рішення

- Оболонка — **Tauri 2**: настільні й мобільні збірки, системний вебрушій
  замість вбудованого Chromium.
- Логіка даних — бібліотека **`notes-core` на Rust** без залежності від
  Tauri.
- Інтерфейс — **React + TypeScript + Vite**, редактор **CodeMirror 6**.

## Розглянуті варіанти

- **Electron** — зрілий, але немає мобільних платформ, а інсталятор важить
  100+ МБ.
- **Flutter** — один рушій для всіх платформ, але слабша екосистема для
  Markdown-редакторів і візуалізацій (графи, полотно, Mermaid).
- **React Native** — немає повноцінних настільних платформ, складна
  інтеграція CodeMirror.

## Наслідки

- Інсталятори малі (одиниці МБ), споживання пам'яті низьке.
- Вебрушії різні на різних ОС (WebView2, WKWebView, WebKitGTK), тож
  інтерфейс треба перевіряти на кожній.
- Ядро можна використати повторно: CLI, сервер синхронізації, тести без UI.
