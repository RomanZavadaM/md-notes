# Архітектура

## Шари

```
┌──────────────────────────────────────────────┐
│ Інтерфейс: React + TypeScript (desktop/mobile)│  app/src
├──────────────────────────────────────────────┤
│ Tauri 2 — команди, діалоги, вікна            │  app/src-tauri
├──────────────────────────────────────────────┤
│ Ядро notes-core (Rust)                       │  crates/notes-core
│  сховища · нотатки · розбір Markdown         │
│  індекс · вкладення · запити · синхронізація │  (наступні версії)
├──────────────────────────────────────────────┤
│ Провайдери сховищ                            │
│  локальна ФС · OpenDAL · Git (gitoxide)      │  (див. ADR-0003)
└──────────────────────────────────────────────┘
```

**Ядро** — незалежна бібліотека без залежності від Tauri чи інтерфейсу. Усе,
що стосується даних, живе тут і покривається тестами. Шар Tauri лише
перетворює виклики інтерфейсу на виклики ядра (`app/src-tauri/src/lib.rs`).

**Інтерфейс** не працює з файлами напряму, а викликає команди Tauri через
типізовані обгортки (`app/src/api.ts`).

## Ядро `notes-core` (v0.1)

| Модуль | Відповідальність |
|---|---|
| `paths` | Шляхи всередині сховища: завжди відносні, з `/`. Відхиляє `..`, абсолютні шляхи й букви дисків, тож вийти за межі сховища неможливо. Очищує імена файлів від символів, заборонених на будь-якій платформі. |
| `markdown` | Front matter, `[[вікі-посилання]]`, `#теги`, заголовок. Перед пошуком маскує код (блоки й `inline`), щоб не знаходити посилання в прикладах коду. |
| `note` | Структура `Note`: вміст, властивості, теги, посилання, заголовок. |
| `vault` | Відкриття та ініціалізація сховища, дерево файлів, читання, атомарний запис, створення, перейменування, кошик, пошук нотатки за посиланням. |
| `index` | Індекс SQLite: нотатки, посилання з контекстом, теги, `aliases`, повнотекстовий пошук FTS5. Інкрементальна синхронізація за часом зміни і розміром файлу. |
| `refactor` | Зміни на рівні сховища: перейменування й переміщення з оновленням `[[посилань]]`. |

### Принципи

- **Файли — джерело правди.** Індекс (з v0.2) лише прискорює роботу і
  завжди перебудовується з файлів.
- **Атомарний запис.** Нотатка спершу пишеться у тимчасовий файл
  `*.mdnotes-tmp`, а потім перейменовується поверх оригіналу. Збій посеред
  запису не залишить напівзаписаного файлу.
- **Нічого не видаляється назавжди.** «Видалення» переносить файл у
  `.mdnotes/trash/<час>/`.
- **Відкриття не змінює папку.** `Vault::open` лише читає. Службову папку
  створює `Vault::init`, коли вона справді потрібна.

## Команди Tauri

| Команда | Ядро |
|---|---|
| `open_vault(path)` | `Vault::open` |
| `get_tree()` | `Vault::tree` |
| `read_note(path)` / `save_note(path, content)` | `read_note` / `write_note` |
| `create_note(dir, title)` / `create_folder(parent, name)` | `create_note` / `create_folder` |
| `rename_entry(from, to)` | `refactor::rename_with_links` |
| `trash_entry(path)` | `move_to_trash` + `Index::sync` |
| `resolve_link(target)` | `Index::resolve` |
| `list_notes()` / `list_tags()` | `Index::notes` / `Index::tags` |
| `backlinks(path)` / `unresolved_links()` | `Index::backlinks` / `Index::unresolved_links` |
| `search(query, limit)` | `Index::search` |

Подія `vault-changed` надходить в інтерфейс, коли файли змінено поза
застосунком (стеження через `notify`, лише настільні ОС).

Права вікна задаються в `app/src-tauri/capabilities/default.json`: базові
можливості Tauri, системний діалог вибору папки і відкриття зовнішніх
посилань у браузері.

## Інтерфейс (v0.1)

- `App.tsx` — стан застосунку, автозбереження (0,8 с після останньої зміни,
  а також `Ctrl/Cmd+S`), перехід за посиланнями.
- `components/Editor.tsx` — CodeMirror 6 з підсвіткою Markdown і мов коду.
- `components/Preview.tsx` — рендер через react-markdown (remark/rehype) з
  GFM. `[[Посилання]]` перетворюються на внутрішні посилання. Сирий HTML не
  рендериться, що захищає від виконання скриптів із нотаток.
- `components/FileTree.tsx` — дерево файлів.
- Теми задаються CSS-змінними. Ширина вікна до 720 px вмикає мобільне
  компонування: бічна панель відкривається поверх вмісту.
