# Пресети нового сховища

MD Notes може створити нове сховище в **існуючій порожній папці**. Пресет — це лише початкова структура звичайних папок і Markdown-файлів; він не створює закритого формату даних.

## Безпека

- Пресет ніколи не накладається на папку, де вже є файли або каталоги.
- Перевірка порожньої папки виконується **до** створення `.mdnotes`.
- Якщо папка непорожня, операція завершується помилкою, а наявні файли не змінюються.
- Відкриття існуючого vault лишається окремою дією і не запускає preset creation.
- Останній vault не відкривається автоматично при старті. Для нього потрібна явна дія користувача «Відкрити останнє сховище».

## Empty

Створюється тільки стандартна службова структура MD Notes:

- `.mdnotes/config.json`;
- `.mdnotes/templates/`;
- `.mdnotes/.gitignore`.

У видимій частині vault не створюється жодної нав'язаної папки.

## PARA

Створюються чотири звичайні каталоги:

- `Projects/`;
- `Areas/`;
- `Resources/`;
- `Archives/`.

Назви залишено канонічними для методики PARA. Користувач може перейменувати або видалити їх як звичайні папки.

## Zettelkasten

Створюються:

- `Notes/`;
- `Sources/`;
- `daily/`;
- `.mdnotes/templates/zettel.md`.

`zettel.md` — звичайний Markdown-шаблон. Він не є обов'язковим форматом нотатки і може бути змінений або видалений користувачем.

## Межі поточного slice

- Пресети застосовуються лише під час створення нового vault.
- Міграції між пресетами немає.
- Existing vault не переплановується і не перебудовується автоматично.
- Runtime GUI-перевірка має бути окремо підтверджена в реальній Tauri-збірці; CI/build не прирівнюється до runtime validation.
