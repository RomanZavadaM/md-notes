# MD Notes v0.3.23 — нотатки до випуску

Дата: 30.10.2026

## Головна зміна

У дереві файлів з'явився перший безпечний зріз групових операцій:

- `Ctrl` у Windows/Linux або `Cmd` у macOS додає чи знімає елемент із вибору;
- `Shift` вибирає видимий діапазон елементів;
- звичайний клік повертає одиночний вибір і звичне відкриття;
- кілька вибраних файлів і папок можна одним підтвердженням перемістити в `.mdnotes/trash/`;
- якщо вибрано папку разом з елементом усередині неї, вкладений елемент не обробляється вдруге;
- після пакетного переміщення в кошик вкладки видалених нотаток прибираються безпечно;
- якщо частина пакетної операції вже виконалась, а наступний елемент дав помилку, інтерфейс узгоджується з фактично виконаною частиною, а невиконані елементи лишаються вибраними для повторної спроби.

Пакетне переміщення між папками та пакетне перейменування **не входять** у цей випуск.

## Приймання

Власник перевірив Windows portable candidate r1 і дав практичне приймання: «вроді все добре». Це достатня підстава для релізного checkpoint, але не твердження про вичерпне тестування всіх крайових сценаріїв.

До інтеграції продуктової зміни CI для PR #186 пройшов успішно; окремий Windows runtime artifact також був успішно зібраний і перевірений на цілісність.

## Backup / restore

Механізм резервного копіювання та відновлення сховища, випущений у v0.3.22, залишається в продукті:

- backup створює переносимий ZIP з manifest і SHA-256;
- відкриті нотатки перед копіюванням зберігаються;
- нотатки, вкладення, конфігурація, шаблони й кошик входять до копії;
- `.git`, `.mdnotes/cache` та тимчасовий системний шум не входять;
- зашифроване сховище копіюється без розшифрування, приватні ключі відновлення до архіву не додаються;
- restore виконується лише в нове сховище, без мовчазного перезапису наявного.

Окремого ручного owner runtime-тесту backup/restore не проводилось; функція має автоматизовані desktop-перевірки.

## Пакети й обмеження

Реліз публікується як prerelease для лінійки 0.x з пакетами Windows, macOS і Linux, START/source, SHA256SUMS та legal notices. Збірки не підписані й не нотаризовані.

Мобільний runtime на фізичних Android/iOS пристроях і WebDAV лишаються в backlog.
