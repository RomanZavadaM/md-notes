# MD Notes v0.1.0 — release notes

Дата: **01.10.2026** · Tag: `v0.1.0` · Release PR: #1

## Що входить

- відкриття локальної папки як сховища, дерево файлів (папки першими, службові папки приховано);
- створення нотаток і папок, перейменування, переміщення в кошик `.mdnotes/trash/`;
- редактор CodeMirror 6 з підсвіткою Markdown і мов коду;
- перегляд (GitHub Flavored Markdown), режими «Редактор», «Поруч», «Перегляд»;
- автозбереження через 0,8 с і `Ctrl/Cmd+S`, атомарний запис файлів;
- `[[вікі-посилання]]` з переходом і створенням відсутньої нотатки;
- `#теги` і властивості YAML front matter, рядок стану з тегами та помилками властивостей;
- світла, темна і системна теми, компонування для вузьких екранів;
- приклад сховища `sample-vault/`, документація, ADR-0001…0006.

## Пакети

Windows (MSI, NSIS setup), macOS (universal), Linux (AppImage, deb, rpm).

## Обмеження

- збірки **не підписані**: Windows SmartScreen і macOS Gatekeeper можуть попереджати при запуску;
- runtime-перевірки у вікні застосунку в межах цього checkpoint не виконувалися; перевірено CI (тести ядра на трьох ОС, clippy, перевірка типів і збірка інтерфейсу);
- START/source пакет і `SHA256SUMS.txt` у цьому релізі відсутні — додаються з наступного checkpoint;
- реліз опубліковано з файлом MIT `LICENSE`; подальший ліцензійний статус описано в `docs/LEGAL_AND_COPYRIGHT.md`.
